
# Weather Icon Display

A responsive weather condition display built using HTML5, CSS3, and JavaScript.

## Features
- Dropdown to select weather conditions
- Dynamic weather icons and descriptions
- Background changes based on the selected condition
- Default state before selection
- Responsive design
- No external API required

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open index.html in a web browser.
3. Select a weather condition from the dropdown.
